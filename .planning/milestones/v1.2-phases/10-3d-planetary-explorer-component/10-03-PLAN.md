    1. Import * as THREE from 'three', OrbitControls, withBasePath from '@/lib/seo', latLonToVector3 from '@/lib/kids/planets', and generateBoundaryPoints, easeOutCubic from './planetary-math'.
    2. Implement buildPlanetCartographyScene(planet: Planet, camera: THREE.PerspectiveCamera, controls: OrbitControls) returning:
       { scene, pinMeshes, focusFeature, updateScene, dispose }:
       - Planet sphere: radius 4.8, 128x64 SphereGeometry. Load texture map via withBasePath matching planet (earth.jpg, moon.jpg, mars.jpg, mercury.jpg, venus_surface.jpg). For Earth, add cloud sphere (radius 4.83) with earth_clouds.jpg, transparent true, opacity 0.5.
       - Atmospheric rim glow shader: SphereGeometry (radius 4.8 * 1.045), ShaderMaterial with additive blending, BackSide, transparent true, colored with planet.accentColor.
       - Lighting: AmbientLight (color 0xffffff, intensity 0.35), DirectionalLight (Sun light at position [35, 15, 25], intensity 1.8), and rim DirectionalLight colored with planet.accentColor (intensity 0.55).
       - Boundary rings: For each of the 7 planet.features, call generateBoundaryPoints(lat, lon, radiusDeg, 4.8) to generate closed Vector3 loops. Create LineLoop with LineBasicMaterial (color matching feature.accentColor or planet.accentColor, transparent true, opacity 0.85). Elevate at 4.815 to prevent Z-fighting per D-03.
       - Hotspot beacon pins: At each feature's latLonToVector3(lat, lon, 4.825), place a small SphereGeometry pin mesh (radius 0.12) with MeshStandardMaterial (emissive glow). Set userData = { featureIndex: idx, featureId: feat.id }.
       - Implement pulsing pin animation in updateScene(delta: number, elapsed: number): scale pin meshes by (1 + Math.sin(elapsed * 4) * 0.18) and slowly rotate planet globe (0.02 * delta).
       - Implement focusFeature(featureIndex: number, onComplete?: () => void):
         Uses glideCameraToFeature pattern from RESEARCH.md Pattern 4. Calculates surface position vector, zoom distance (11.5), and lerps camera position using easeOutCubic over ~1.2 seconds. Attaches listener to controls 'start' event to halt gliding immediately if user touches or drags the globe.
       - Implement raycastFeaturePins(event: PointerEvent, container: HTMLElement): number | null returning clicked feature index or null.
       - Implement dispose() to clean up all geometries, materials, and textures.
