# Plan 19-01: Enrich planetary schemas, dimensions, and bilingual telemetry field notes

## Context
Update `src/lib/kids/planets.ts` with verified astronomical telemetry from `how-big-is-big/src/bodies.js`, including authentic planetary radii, distance from the Sun, light travel times, and 3 cycling field notes per celestial body (`primaryFact` and `fieldNotes`), fully localized in both Bahasa Melayu and English. Expand `PlanetId` and `SubjectId` to include outer planets (`jupiter-astronomy`, `saturn-astronomy`, `uranus-astronomy`, `neptune-astronomy`) with empty province features for observational exploration.

## Tasks
1. **Extend Schema Interfaces:**
   - Add `radiusKm`, `distanceFromSun`, `primaryFact`, `primaryFactMs`, `fieldNotes`, `jumpDistance` to `Planet`.
   - Add `"astronomy"` to `SubjectId`.
   - Add `"jupiter-astronomy" | "saturn-astronomy" | "uranus-astronomy" | "neptune-astronomy"` to `PlanetId`.
2. **Enrich Existing 5 Worlds:**
   - Add authentic astronomical dimensions and field notes to Earth, Moon, Mars, Venus, and Mercury while maintaining all 35 geological features and prompt curriculum mappings.
3. **Register Outer Worlds:**
   - Add Jupiter (Musytari), Saturn (Zuhal), Uranus (Uranus), Neptune (Neptun) to `PLANET_WORLDS` with accurate astronomical data and `features: []`.
4. **Update Tests:**
   - Update `planets.test.ts` and `planets-i18n.test.ts` to assert presence of new telemetry fields and 0 missing translations across all planets.
