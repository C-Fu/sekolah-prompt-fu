# Plan 18-01: Optimize and deploy planetary textures and attribution

## Context
Phase 18 imports high-resolution planetary texture maps from `how-big-is-big/maps/` (Mercury, Venus, Mars, Jupiter, Saturn, Neptune) to replace/supplement existing lower-res textures with crisp 2048x1024 equirectangular textures, under CC-BY-4.0 Solar System Scope licensing.

## Tasks
1. **Optimize and Resize Textures:**
   Use `ffmpeg` to resize source maps from `how-big-is-big/maps/` to 2048x1024 with 85% JPEG quality:
   - `mercury.jpg` (from `how-big-is-big/maps/mercury.jpg`) -> `public/images/planets/mercury.jpg`
   - `venus_surface.jpg` (from `how-big-is-big/maps/venus.jpg`) -> `public/images/planets/venus_surface.jpg`
   - `mars.jpg` (from `how-big-is-big/maps/mars.jpg`) -> `public/images/planets/mars.jpg`
   - `jupiter.jpg` (from `how-big-is-big/maps/jupiter.jpg`) -> `public/images/planets/jupiter.jpg`
   - `saturn.jpg` (from `how-big-is-big/maps/saturn.jpg`) -> `public/images/planets/saturn.jpg`
   - `neptune.jpg` (from `how-big-is-big/maps/neptune.jpg`) -> `public/images/planets/neptune.jpg`
2. **Update Attribution Document:**
   Update `public/images/planets/ATTRIBUTION.md` to include Solar System Scope (CC BY 4.0, NASA mission imagery basis) for Mercury, Venus, Mars, Jupiter, Saturn, and Neptune, and note procedural atmosphere treatment for Uranus.
3. **Verify Asset Budget and Dimensions:**
   Ensure all 6 resized images are 2048x1024 and total bundle size additions are well under 2 MB.

## Verification
- Inspect with `file` / `identify` / `ffmpeg` that each image is 2048x1024.
- Verify total byte size of `public/images/planets/`.
- Ensure Next.js build / tests continue to pass.
