# Plan 21-01: Update Telemetry HUD with Coming Soon state for future subject worlds

## Context
Update `planetary-hud.tsx` so when an outer world without active curriculum missions (Jupiter, Saturn, Uranus, Neptune) is viewed in cartography mode, the HUD displays a polished "Coming Soon / Akan Datang" card indicating that subjects like Sejarah and Sains will arrive in future updates, while keeping the curriculum planet HUD clean and familiar.

## Tasks
1. **Add Localization Messages:**
   - Add `comingSoonTitle`, `comingSoonDesc` in `messages/en.json` and `messages/ms.json` under `kids.planets`.
2. **Update `PlanetaryHud` Component:**
   - In `planetary-hud.tsx`, when `planet.features.length === 0`, render a dedicated "Coming Soon" card with the planet's primary astronomical fact, radius, and message about upcoming subjects (Sejarah, Sains).
3. **Update Tests:**
   - Update `planetary-hud.test.tsx` to verify the "Coming Soon" card renders properly for worlds without features.

## Verification
- Run `vitest run src/__tests__/kids/planetary-hud.test.tsx`.
- Run `npm run check:vocab`.
