# Plan 08-01: Author Bilingual MDX Content for 5 KSSR Standard 1 Pilot Levels

## Objective
Author high-quality, syllabus-aligned interactive MDX level files for the 5 pilot KSSR Year 1 subjects (BM, Sains, Matematik, English, Pendidikan Moral) in both Bahasa Melayu (`src/content/kids/ms/`) and English (`src/content/kids/en/`) with zero silent English fallback, adhering to `check-ms-vocabulary.js` rules.

## Proposed Changes

### 1. Author Bahasa Melayu Level MDX Files (`src/content/kids/ms/`)
- `6-1-bm-kucing-peromfu.mdx`:
  - DSKP 5.1: Kata Nama & Kata Kerja.
  - Interactive widgets: `<WordPredictor>` (action verb prediction) & `<DragDropPrompt>` (assembling a scene description prompt).
- `7-1-sains-benda-hidup.mdx`:
  - DSKP 3.1: Benda Hidup vs Benda Bukan Hidup.
  - Interactive widgets: `<PromptDoctor>` (fixing prompt that caused AI to pick a rock) & `<ExampleMatcher>` (matching living criteria).
- `8-1-matematik-tambah-bintang.mdx`:
  - DSKP 2.1: Operasi Tambah dalam lingkungan 20.
  - Interactive widgets: `<StepByStep>` (prompting AI for step-by-step counting) & `<PromptVsMistake>` (selecting prompt that enforces numeric equation format).
- `9-1-english-colorful-toys.mdx`:
  - DSKP 2.1: Simple description & polite role-play.
  - Interactive widgets: `<DragDropPrompt>` (Role + Target + Color constraint) & `<WordPredictor>`.
- `10-1-moral-sahabat-prihatin.mdx`:
  - DSKP 2.1: Tolong-menolong & empati.
  - Interactive widgets: `<PromptDoctor>` (turning blunt prompt into kind, helpful assistance) & `<PromptVsMistake>`.

### 2. Author English Level MDX Files (`src/content/kids/en/`)
- Author mirror levels in `src/content/kids/en/`:
  - `6-1-bm-kucing-peromfu.mdx`
  - `7-1-sains-benda-hidup.mdx`
  - `8-1-matematik-tambah-bintang.mdx`
  - `9-1-english-colorful-toys.mdx`
  - `10-1-moral-sahabat-prihatin.mdx`

## Verification
- Run `npm run check:vocab` -> scans all 24 MS files and passes exit 0.
- Run `npm run check:closure` -> confirms all English and MS MDX files exist.
