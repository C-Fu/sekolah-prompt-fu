# Plan 06-01: Header BM/EN Quick Toggle Component

## Objective
Implement a kid-friendly dual toggle button ("BM | EN") in the `KidsHeader` next to the Music and Settings buttons (on both desktop and mobile dropdown views). The toggle allows single-click switching between Bahasa Melayu (`ms`) and English (`en`), highlights the active language with pixel styling, and invokes `useLocalePreference().setLocale()` with appropriate feedback.

## Proposed Changes

### 1. Create `LanguageToggle` Component
- Create or place `LanguageToggle` in `src/components/kids/layout/language-toggle.tsx` (or directly within header components):
  - Uses `useLocalePreference()` to read the current effective `locale` and call `setLocale()`.
  - Renders a compact segmented/pill button: `[ BM | EN ]`.
  - When current locale is `ms` (or any variant), "BM" segment is highlighted (e.g. active pixel yellow/gold background with dark text) and "EN" segment is inactive.
  - When current locale is `en` (or non-ms), "EN" is highlighted.
  - Clicking "BM" sets locale to `'ms'`; clicking "EN" sets locale to `'en'`.
  - Includes accessible `aria-label` and `aria-pressed` states.
  - Pixel border styling matching existing header buttons (`pixel-border-sm`, height 8 / 32px).

### 2. Integrate into `KidsHeader`
- In `src/components/kids/layout/kids-header.tsx`:
  - Place `<LanguageToggle />` in the desktop nav bar beside `<MusicButton />` and `<SettingsButton />`.
  - Place `<LanguageToggle />` in the mobile dropdown menu.

### 3. Add Tests
- Add unit tests verifying:
  - Renders both "BM" and "EN" segments.
  - Reflects current active locale styling.
  - Calls `setLocale('ms')` and `setLocale('en')` on click.
  - Accessible attributes and state changes.
