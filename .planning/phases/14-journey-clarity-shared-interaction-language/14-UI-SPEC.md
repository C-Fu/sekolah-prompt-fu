### Surface and interaction contracts

| Surface | Visual hierarchy and required interaction |
|---------|--------------------------------------------|
| Title welcome step | Keep Peromfu and the existing pixel panel as the visual anchor. Present a concise localized learning promise in one sentence. Show a clear “Step 1 of 2” state. Footer has a labeled Next action; Back is absent/disabled without taking layout focus. |
| Title destination step | Keep the two destination cards equal in size, hierarchy, prominence, and CTA emphasis; do not label either as recommended or make one the lone green/primary CTA. Each card contains a direct localized action label and one short explanation. The whole card is a semantic link to the existing route (`/map` or `/planets`); no extra third Start CTA. Show “Step 2 of 2” and a labeled Back action. |
| Shared navigation | Home, Earth map, and Planets each have visible BM/EN text plus their familiar icon on desktop and in the mobile navigation menu. Use the existing localized “Solar System” / “Sistem Suria” wording for the hub label. Current lesson context belongs in the lesson section/level labels, not a breadcrumb. Avoid duplicate Home destinations in the same nav group. The locale toggle remains explicit; changing locale must render the complete target locale, never mixed or silently English-fallback copy. |
| Earth map | Keep the illustrated pixel map and existing planetary portal. Name the current location “Earth map” / “Peta Bumi”; preserve the portal's direct text label. A short dismissible map tip may sit in an unobstructed inline area below the map heading/intro, never over the portal, level controls, or tappable map nodes. Each level remains a labeled action with its existing lock/progress distinction. |
| Planetary hub | Preserve the dark space/3D planetary scene and glass HUD; name the hub “Planets” / “Planet”. Keep Earth map navigation labeled, and keep the cartography back action labeled as return to solar-system orbit. A short dismissible tip is one compact inline HUD/callout, positioned away from orbit/map controls, the selected-planet controls, and mission CTA. Treat orbit and cartography as modes of the same `/planets` surface for tip dismissal. |
| Lesson | Keep the current fixed footer as the single home for Back and Next/Continue. In the lesson content/footer context, show level identity, localized current section title, and ordinal (“Step 2 of 7”), not progress dots alone. Dots may remain as supplementary progress only. Next remains visible while locked and has adjacent visible localized guidance. Return action and completion/coming-soon links resolve to the originating hub (allowlisted map vs planets); direct/invalid origin deterministically falls back to Earth map. Never reset or rewrite saved learning progress during navigation. |

### Responsive behavior

- Keep the two title cards side-by-side at comfortable widths and stack them in the same order below the existing `sm` breakpoint; in either layout both cards keep the same visual weight and readable action/description.
- Use natural wrapping for BM and EN labels, tips, section titles, and disabled explanations. Do not truncate important navigation/action text or rely on tooltips. Cards grow to the taller translated content rather than clipping it.
- Keep labeled navigation discoverable on both desktop and mobile: desktop labels accompany icons; mobile labels are in the opened, keyboard-operable menu. The menu trigger itself has a localized accessible name.
- Keep lesson progress text and fixed footer controls visible without overlapping lesson content; reserve scrollable space for content. At narrow widths, allow footer rows to wrap/stack without hiding Next or the locked explanation.
- Map and planetary callouts reflow with their containing layout and do not cover primary controls. Desktop-only map scroll controls remain supplementary; map content can still be traversed by its existing scroll surface.
- Primary controls should retain a minimum 44px hit area where layout permits. Provide visible keyboard focus and preserve semantic `Link` for route changes and `button` for local state/dismissal actions. Phase 15 owns the broader viewport/input accessibility certification.

| Token | Value | Usage |
|-------|-------|-------|

| sm | 8px | Tight controls and label spacing |

## Typography

Use exactly these four sizes for the journey contract; roles may scale down responsively only when needed to prevent clipping. Keep the current Schoolbell production face, warm high-contrast ink, and pixel text shadow on display headings while the comparison below is evaluated. Keep long translated content at full readable line-height. Typography exploration must preserve the app's pixel-art/planetary identity and must not trigger a broad visual redesign.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 20px | 400 regular | 1.5 |
| Label / control | 16px | 700 bold | 1.25 |
| Heading | 28px | 700 bold | 1.2 |
| Display | 48px | 700 bold | 1.1 |

Weights: 400 regular and 700 bold only. The app currently loads Schoolbell at 400; use the established CSS bold treatment for emphasis rather than adding another font family. Do not shrink instructions or nav text into decorative microcopy.

### Bounded font comparison (prototype only; no production switch by default)

- Compare the current Schoolbell rendering with **Bubble Sans** and **Comic Neue** using the same existing BM/EN headings, navigation labels, instructions, tips, and lesson-content excerpts. Add another candidate only if a documented technical incompatibility makes both named candidates unusable.
- Evaluate character/glyph coverage and legibility for children in both locales, including BM/EN diacritics and punctuation, at narrow mobile and large desktop widths. Keep the four declared sizes, two weights, existing line heights, colors, and component layouts constant so the comparison isolates typography. Record representative screenshots and any clipping/wrapping differences.
- Check that font assets can be bundled/self-hosted and that a clean static export succeeds without runtime font-network requests. Retain and test the existing Schoolbell-to-system fallback behavior; a fallback must render every comparison string legibly if a preferred font is unavailable.
- **Decision rule:** Schoolbell remains the production font unless a candidate has complete tested glyph coverage, improves measured child-reading results over Schoolbell on the same BM/EN specimen (fewer reading errors or higher correct-reading rate, with no locale/viewport regression), passes the static-export/fallback checks, and receives explicit user approval. If child-reading evidence cannot be collected or results are inconclusive, keep Schoolbell. The planner should add a small prototype/comparison task if feasible; do not silently change the production font or add a font dependency as part of the comparison.

## Color

Preserve existing route-specific backgrounds and established brand colors rather than flattening the map and planetary hub into one theme. The split below is a visual-area/hierarchy guide, not a mandate to recolor the scenes.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | Existing route background: preserve illustrated Earth sky and planetary space (`#020617` where the current scene uses slate-950); warm ink `#2C1810` remains shared header/footer chrome | Keep the established route surface and shared framing; do not recolor the scene to force a uniform background |
| Secondary (30%) | Warm paper `#FEF3C7` / `#FDE68A` and existing themed panel fills | Lesson/title panels and map cards; keep dark text `#2C1810` and supporting text `#5D4037` legible |
| Accent (10%) | Existing green `#16A34A` and blue `#2563EB` (paired, equal prominence); gold `#FFD700` only for current-step/location highlights | Green/blue distinguish the two equal destinations and their corresponding existing portal cues; gold marks current section/location or the step indicator, not all actions |
| Destructive | `#DC2626` | Destructive actions only; none are introduced by this phase |

Accent reserved for: the equal Earth and Planets card trims/icons, matching map-to-planets cue, active lesson-step indicator, and current-location marker only. Keep each card's label/explanation independently legible; color is never the only distinction. Do not assign one destination more visual weight by making its color the sole dominant CTA color.

## Copywriting Contract

All new or changed UI copy belongs in the canonical `messages/en.json` and `messages/ms.json` translation bundles via the existing `next-intl` namespaces. Copy must be concise, concrete, child-directed, and action-led. The BM and EN screens must be complete, equivalent journeys, not partial translation or fallback. Preserve natural Malay vocabulary and existing locale-switch behavior. These strings are canonical wording for the phase; adapt inflection only to fit sentence context while preserving meaning.

| Element | English | Bahasa Melayu |
|---------|---------|---------------|
| Welcome learning promise | Learn to write clear prompts through games, stories, and missions. | Belajar menulis prompt yang jelas melalui permainan, cerita dan misi. |
| Welcome progress | Step 1 of 2 | Langkah 1 daripada 2 |
| Choice progress | Step 2 of 2 | Langkah 2 daripada 2 |
| Step navigation | Back / Next | Kembali / Seterusnya |
| Earth destination action | Start learning | Mula belajar |
| Earth destination explanation | Learn the basics of writing prompts on Earth. | Pelajari asas menulis prompt di Bumi. |
| Planet destination action | Explore planets | Terokai planet |
| Planet destination explanation | Visit planets and choose a subject mission. | Lawati planet dan pilih misi subjek. |
| Shared route labels | Home / Earth map / Planets | Utama / Peta Bumi / Planet |
| Lesson next action | Continue | Teruskan |
| Incomplete activity explanation | Complete the activity first to continue. | Siapkan aktiviti ini dahulu untuk teruskan. |
| First-visit map tip | Choose a level on the map to start learning. | Pilih satu tahap pada peta untuk mula belajar. |
| First-visit planets tip | Choose a planet to explore its subject missions. | Pilih planet untuk menerokai misi subjeknya. |
| Empty state heading | No levels here yet | Belum ada tahap di sini |
| Empty state body | No levels are available yet. Explore the planets instead. | Belum ada tahap lagi. Terokai planet sebagai pilihan lain. |
| Error state | This lesson could not load. Return to {hub} and choose it again. | Pelajaran ini tidak dapat dibuka. Kembali ke {hub} dan pilih sekali lagi. |
| Unavailable lesson heading | Lesson coming soon | Pelajaran akan datang |
| Unavailable lesson return action | Return to {hub} | Kembali ke {hub} |
| Tip dismissal | Got it | Faham |
| Menu trigger | Open menu / Close menu | Buka menu / Tutup menu |
| Destructive confirmation | None — this phase adds no destructive action. | Tiada — fasa ini tidak menambah tindakan yang memusnahkan data. |

CTA contract: the two title destination actions are co-primary and equally prominent (“Start learning” / “Mula belajar” and “Explore planets” / “Terokai planet”). On the lesson screen the primary progression action is the existing footer’s Next/Continue (localized “Seterusnya” / “Teruskan” per existing control naming). Never leave a third title-level Start action competing with the two routes. The error `{hub}` value is an allowlisted localized label (“Earth map” / “Peta Bumi” or “Planets” / “Planet”), never a user-supplied URL.

Empty/error handling: there is normally no empty title-choice state because the two destinations are fixed routes. If a map has no selectable levels, use the empty copy above; if lesson loading fails, use the error copy plus the context-aware return link. Coming-soon content remains distinct from a load failure. There is no delete/reset/irreversible action, so no confirmation dialog is added.
