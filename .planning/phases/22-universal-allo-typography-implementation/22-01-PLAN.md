# Plan 22-01: Universal Allo typography implementation across root layout, CSS, and components

## Context
Replace Google Schoolbell and legacy sans fonts with Josh Puckett's Allo typeface across all elements in Sekolah Prompt-Fu. Self-host WOFF2 variable fonts with optical sizing and friendly curves, delivering a playful, cheerful, cheeky yet adult-friendly design.

## Tasks
1. **Define `@font-face` Rules in `globals.css`:**
   - Add `@font-face` for `"Allo"` variable font pointing to `/fonts/allo/AlloVariable.woff2`.
   - Add `@font-face` declarations for italic / oblique weights.
   - Configure `--font-kids: "Allo", system-ui, -apple-system, sans-serif;`.
   - Set `font-family: var(--font-kids)` on `body`, `.prose`, headings, buttons, and badges.
2. **Clean up Root Layout:**
   - Remove `Schoolbell` import and instantiation from `src/app/layout.tsx`.
   - Apply clean font variable and font class.
3. **Verify Typography and Visual Harmony:**
   - Verify headings, buttons, and HUD render properly.
   - Run verification test suites.

- Run `npm run check:closure`.
